# Lieferblick

An interactive supply chain visibility dashboard prototype by **Prithviraj Shetty**, focused on inbound shipments to German production sites. The portfolio role represented here is **Supply Chain Analyst**.

## Run it

Open `index.html` in a modern web browser. No installation, server, or account is required.

## What’s included

- Shipment KPIs and inventory coverage indicators.
- Search and filters for status and destination.
- Germany route overview with illustrative hubs.
- Shipment detail messages with suggested next actions.
- CSV export of the filtered shipment list.
- Responsive layout for desktop and mobile.

All suppliers, shipments, times, routes, and inventory levels are fictional demo data. They are not live tracking information.
